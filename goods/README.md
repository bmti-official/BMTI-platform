# BMTI 키링 굿즈 제작 파일

16유형 아크릴 키링용 자산입니다. 웹사이트로 배포되지 않는 폴더입니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `cutout/{CODE}.png` | 인쇄용 **고해상도 누끼**(투명 PNG). 원본 3D 렌더에서 배경 제거 |
| `qr/bmti-qr.png` | 메인 페이지 QR (`https://bmti-official.co.kr`, 오류정정 H) |
| `print/front/{CODE}.png` | **앞면** — 캐릭터 + 별명 + 유형 코드 |
| `print/back/{CODE}.png` | **뒷면** — QR + BMTI 로고 + 주소 |
| `print/preview.png` | 16종 앞/뒤 검수용 시트 |

## 인쇄 규격

- **60 × 60 mm** + 사방 **3 mm 재단여백** = 66 × 66 mm
- **300 DPI**, 780 × 780 px, RGB
- **빨간 실선 = 재단선(60mm)** — 업체에 넘기기 전 삭제하거나, 업체 양식의 칼선 레이어로 옮기세요
- 아크릴 3T, 양면 인쇄 기준. 규격이 다르면 `tools/make-keyring.py`의 `SIZE_MM` / `BLEED_MM` / `DPI` 만 바꿔 다시 실행

## ⚠️ 손봐야 하는 유형

원본이 '캐릭터 한 마리'가 아니라 **소품·사람이 함께 있는 장면**이라, 아래 4종은 배경 제거 후에도
주변 요소가 남습니다. 키링에는 캐릭터만 들어가야 하므로 **수동 보정을 권합니다.**

| 코드 | 남아 있는 것 |
|---|---|
| ACDZ | 옆에 서 있는 사람 |
| OCDZ | 사람 + 소총 |
| OCQM | 인체 해부도 액자 |
| OLDZ | 고양이 |
| OLQM | 머리 왼쪽 경계가 원본부터 흐려서 살짝 파임 |

## 다시 만들기

```bash
.venv/bin/python3 tools/make-cutouts.py   # 원본 → 누끼
.venv/bin/python3 tools/make-keyring.py   # 누끼 + QR → 앞/뒤 조판
```

- 배경이 덜 지워지거나 캐릭터가 파이면 `tools/make-cutouts.py`의 `TOL`(기본 34) 또는
  코드별 예외인 `TOL_OVERRIDE` 값을 조절하세요. **값이 작을수록 덜 지웁니다.**

## 제작 전 확인

- 캐릭터는 생성형 AI로 만든 자산입니다. **굿즈(머천다이즈) 제작이 허용되는지 해당 AI 서비스 약관을 확인하고 캡처해 보관**하세요.
- 지인 배포를 넘어 판매·홍보물로 쓸 계획이면 '말랑이' **상표 출원**을 먼저 진행하는 것을 권합니다.
