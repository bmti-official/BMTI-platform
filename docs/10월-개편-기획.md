# 10월 개편 기획

2026년 9월에 정한 것. 작업하면서 어긋나면 이 문서를 먼저 고친다.

## 1. 하단 네비 — 두 층으로

```
루트        다이어리 · [캐릭터] · 자기점검
다이어리    ‹ 이전 · 오늘 쓰기 · [캐릭터] · 기록·발견 · 각도기록
자기점검    ‹ 이전 · 둘러보기 · [캐릭터] · 바로플리 · 내 보관함
```

- 누끼 캐릭터는 **어느 층에서도 가운데 고정**. 알약 위에 떠 있는 지금 모양 그대로.
- `다이어리`를 누르면 **오늘 쓰기가 열린 채로**, `자기점검`을 누르면 **둘러보기가 열린 채로** 하단 바만 바뀐다. 허브 화면을 두지 않는다.
- `이전`은 루트로 나간다. **휴대폰 뒤로가기·가장자리 스와이프도 같은 곳으로** 가야 한다.
- 지금 어디인지는 **홈 버튼과 마이페이지 사이**에 큰 제목으로 적는다.
- 알약은 지금도 `4칸 + 가운데 빈자리`라 컨텍스트 바가 그대로 맞는다. 루트만 `2칸 + 가운데`로 널찍해진다.

### 이름
| 자리 | 이름 | 비고 |
|---|---|---|
| 주간 움직임 측정 | **각도기록** | 오늘(매일) · 주간(매주) · 발견(매달)로 주기가 가지런해진다 |
| 큐레이션 | **읽을거리** | 관리자 탭 이름은 나중에 맞춰도 된다 |
| 마이플리 | **내 보관함** | 플리·카드·읽을거리를 다 담으니 '플리'는 좁다 |
| 바로플리 | 그대로 | 관리자·SQL·문서·음성 대본에 이미 박혀 있다. **아이콘만 재생 버튼으로** |
| 자기점검 | 그대로 | |

## 2. 둘러보기 — 읽을거리와 바로카드를 한 격자에

- 가로 3칸, **4:5 세로**. 바로카드 격자를 그대로 쓴다.
- 읽을거리 표지를 4:5로 다시 자른다 (글이 10편뿐이라 감당된다).
- 모서리 표시로 갈래를 알린다 — 읽을거리는 **장수**(`1/14`), 동작은 **시간**(`2:30`).

## 3. 내 보관함 — 인스타 마이페이지 모양

- 위: **읽기 전용 요약**만. 닉네임 · 내 유형 캐릭터 · 저장 개수(`플리 4 · 카드 12 · 읽을거리 3`).
  고치는 건 위쪽 마이페이지 알약으로 보낸다. 두 군데서 고치게 하지 않는다.
- 가운데: `플리 | 바로카드 | 읽을거리` 갈래 버튼.
- 아래: 둘러보기와 **같은 3칸 4:5 격자**.
- 빈 갈래일 때 안내 문구는 갈래마다 다르게.

## 4. 다이어리 항목 정리

### 없앤다
- `오늘 평소보다 무리했나요` → 오늘의 태그로 옮긴다
- 온보딩 `몸 관리에서 제일 신경 쓰는 건?`
- 리포트: 몽글몽글 포도 송이 · 연속과 공백 · 처음의 다짐 팩트 체크

### 남긴다
- 온보딩 `요즘 하루 대부분 어떻게 지내요?` — **각도 해석의 기준선**이라 꼭 남긴다
- `오늘 운동·스트레칭·산책 했나요?` — 아래 자동 기록과 묶인다

### 태그
- 활동·환경에 다섯 개를 더한다 — 오래 앉음 · 오래 선 자세 · 많이 걸음 · 무거운 물건 들기 · **업무과다**(서류 더미 아이콘, 새로 그림)
- **부담 점수** = 상태·기타 + 활동·환경. 음식 섭취는 점수에서 빼고 막대그래프에만 넣는다.
  - 2점 — 진통제 · 방전됨 · 무거운 짐 · 무거운 물건 들기 · 업무과다
  - 1점 — 나머지 부담 태그
  - 0점 — 수분 보충 · 영양제
  - `생리 중`은 1점이되 문구에 **'무리했다'는 말을 쓰지 않는다**. 본인이 고를 수 있는 게 아니다.
- 고를 수 있는 개수는 제한 없음. 많이 고를수록 그날 부담이 컸던 것으로 본다.
- 과거 `overwork` 기록은 옮기지 않는다. 지난달은 그대로 둔다.

### 태그 막대그래프
- 갈래별(음식 섭취 · 활동·환경 · 상태·기타)로 많이 고른 태그를 막대로.
- 분모는 **이번 달 기록한 날 수**. "기록한 18일 중 12일(67%)".

## 5. 바로카드 완수 자동 기록

- 한 세트 이상 = **했음**, 끝까지 = **완주**. 둘을 나눠 담는다.
- **일기를 자동으로 만들지 않는다.** `card_finishes`에만 쌓고, 일기를 열 때 "오늘 두 번 하셨네요" 하고 채워 준다. 빈 일기가 생기면 연속·월간 집계가 오염된다.
- 사용자가 끌 수 있다 (`users.auto_exercise`).
- 비로그인 손님은 기록하지 않는다.
- 운동 종목에 **`바로카드`를 더한다**. 지금 목록에 마사지도 없고 바로카드 운동이 들어갈 자리도 없다.

## 6. 각도기록 — 움직임 측정

구글 미디어파이프(MediaPipe Pose). **브라우저에서만 돌리고 사진은 기기 밖으로 내보내지 않는다.**

### 무엇을 재나 — 촬영 두 번에 값 세 개
| 촬영 | 동작 | 얻는 값 |
|---|---|---|
| 측면 1회 | 가만히 서기 → 허리 앞으로 굽히기 | 목 숙임(정지) · 몸통 굽힘 가동범위 |
| 정면 1회 | 팔 옆으로 천천히 들어 올리기 | 어깨 들림 가동범위 |

- 측면 촬영의 **굽히기 전 서 있는 프레임**이 그대로 정지 자세 측정이 된다.
- `허리 뒤로 펴기`는 보상 동작이 많고 허리에 부담이라 2단계로 미룬다.
- **고개 좌우 돌리기 같은 회전은 2D로 못 잰다.** 넣지 않는다.
- 항목은 당분간 **고정**. 매주 다른 걸 재면 추세가 안 나온다. 쌓인 뒤에 '기본 + 관심 부위 1개'로 연다.

### 재는 방법
- **일요일~토요일 중 아무 때나 한 번.** 같은 주에 다시 재면 덮어쓴다.
- 가이드 실루엣(측면 90도 고정) · 어깨 너비 픽셀로 거리 검사 · 무릎이 굽으면 되돌리기
- 측면에서 몸이 비스듬하면 좌우 어깨·골반 랜드마크 간격으로 잡아낸다
- 헐렁한 옷은 어깨선이 안 잡히니 미리 알린다
- 실패하면 **다시 찍기**. 세 번 연달아 실패하면 **가이드를 다시 보여준다**
- 측정 품질 점수를 같이 담고, 낮은 날은 추세에서 뺀다

### 보여주는 법
- **절대 각도를 보여주지 않는다.** `거북목 18도`는 의학 측정으로 읽힌다.
- 기록 발견에서 **지난주와 비교 + 지난달 평균과 비교**. 지난달 비교는 2개월째부터.
- 추세 꺾은선은 **4회부터**. 그전에는 점만 찍는다.

### 인과 표현 금지
주 1회 네 점으로는 인과를 말할 수 없고, '효과가 있습니다'는 의료 광고로 읽힌다.
**"A 때문에 B"가 아니라 "A한 주에 B였다"**로만 쓴다.

| 쓰면 안 됨 | 이렇게 |
|---|---|
| 바로카드를 꾸준히 해서 허리 굽힘이 8도 늘었어요 | 허리 굽힘이 8도 늘어난 주에는 바로카드를 5번 하셨어요 |
| 거북목이 개선되고 있어요 | 목을 숙인 정도가 지난주보다 3도 줄었어요 |
| 스트레스 때문에 각도가 나빠졌어요 | 부담 태그가 많았던 주에는 각도가 조금 줄어드는 편이었어요 |

태그 × 각도 교차는 **첫 달부터** 넣는다. 그래서 이 규칙이 특히 중요하다.

## 7. 알림 — 웹 푸시로

카카오톡은 문턱이 높다. 알림톡은 **휴대폰 번호**(지금 안 받는다) + 비즈앱 전환·검수 + 템플릿 심사 + 건당 과금이 필요하고, 친구톡은 광고성으로 분류되기 쉬워 야간 발송이 막힌다.

- **1단계** — 다이어리를 열었을 때 띄우는 배너(`이번 주 재기, 아직이에요`) + 웹 푸시. 비용 0.
- **2단계** — 사용자가 늘고 iOS 비중이 문제되면 알림톡 검토.
- iOS는 **홈 화면에 추가해야** 푸시를 받는다(16.4+). 배너가 그 구멍을 메운다.
- 지금 가입할 때 체크하는 `알림 받기`는 사전예약 명단용일 뿐 **진짜 구독이 아니다.** 새로 만들어야 한다.
- **VAPID 키 한 쌍**과 매주 보내는 서버 작업(Edge Function + pg_cron)이 필요하다.

## 8. 뉴스카드 본문 — 새 글부터

기존 10편은 긴 글 그대로 둔다.

- 이미지 5~10장, 글 분량은 유지. 한 장에 2~3문장.
- **같은 사진에서 넘어갈 때는 사진을 밀지 않는다.** 사진은 가만히 두고 글만 바꾼다. 똑같은 사진이 빠지고 들어오면 고장 난 것처럼 보인다.
- 데이터는 사진별로 묶는다 — `[{사진, 글[]}, …]`. 평평한 목록이면 같은 사진을 매번 다시 고르게 된다.
- 글은 **아래 띠에 그라데이션을 깔고** 얹는다. 바로카드처럼 위아래 자리 조절을 붙여 사진 주인공을 피한다.
- 한 장 **90자**, 전체 **20장**까지. 넘으면 관리자에서 빨갛게.
- 읽다 나가면 **몇 장까지 봤는지 기억**한다.
- 표지는 **첫 장**을 그대로 쓴다. 마지막 장은 **바로플리 자리**.

### 검색 유입을 잃지 않으려면
읽을거리는 정적 페이지(`/magazine/*.html`)로 뽑혀 **사이트맵에 올라가 있다.** 생성기가 글의 `body` 한 덩어리를 읽는다.
글이 이미지 위로만 가면 이 유입이 끊긴다. **슬라이드를 원본으로 두되, 저장할 때 `body`를 자동으로 이어 붙인다.** 생성기는 손댈 게 없다.
