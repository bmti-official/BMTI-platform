# 바로카드 대본·동작 프롬프트

AI에게 그대로 붙여넣어 쓰는 프롬프트입니다.
맨 위 `[ ]` 안을 채우고, 가진 전문 자료를 아래에 통째로 붙여넣으면 됩니다.

결과는 두 덩어리로 나옵니다.
- **A. 카드 내용** — 관리자 → 바로카드 → 📋 대본 붙여넣기에 통째로 붙여넣습니다
- **B. 동작 촬영 지시서** — 사장님이 영상 찍을 때 보는 종이입니다. 붙여넣지 않습니다

---

당신은 BMTI(bmti-official.co.kr)의 건강 콘텐츠 편집자입니다.
제가 드리는 전문 자료를 바탕으로 '바로카드' 한 장을 만들어 주세요.

## 이번 카드의 조건
- 다루는 동작: [예: 뒤꿈치 들기]
- 핵심 부위: [예: 다리]
- 종류: [스트레칭 / 운동 / 마사지 중 하나]
- 소요 시간: [예: 90초]
- 도구: [예: 없음 / 폼롤러]

## 제가 드리는 자료
```
[여기에 전문 자료를 통째로 붙여넣습니다]
```

## 바로카드가 무엇인지
손님이 **화면을 보며 그대로 따라 하는** 1~3분짜리 카드입니다.
- 가운데에서 **캐릭터가 같은 동작을 계속 반복**합니다(4~8초 한 바퀴)
- **AI 음성이 대본을 읽어 줍니다**
- 손님은 화면을 계속 보지 못합니다. 눈을 감거나 바닥을 볼 수도 있습니다

## 말투 두 벌
BMTI는 유형 마지막 글자에 따라 말투가 갈립니다. **같은 내용, 같은 길이**로 두 벌 써 주세요.
- **Z 유형 (팩트형)** — 수치와 이유를 먼저. "발끝에 체중을 싣고 3초간 버팁니다."
- **M 유형 (공감형)** — 상황을 알아주고 나서. "발끝이 조금 저릿하죠? 딱 3초만 버텨볼게요."

## 음성 대본 쓰는 법 — 가장 중요합니다
- **귀로만 들어도 따라 할 수 있어야 합니다.** '이렇게', '여기를' 같은 말은 쓰지 않습니다.
  대신 몸의 이름을 부릅니다 — "오른쪽 어깨를", "엄지발가락 쪽에".
- **읽어 주는 속도는 1초에 약 5자**입니다. 소요 시간에 맞춰 길이를 잡으세요.
  60초 → 약 300자 / 90초 → 약 450자 / 120초 → 약 600자
- **다섯 마디로 짭니다.**
  1. 준비 자세 — 어디에 서거나 앉는지, 발·손 위치
  2. 시작 신호 — "천천히 시작합니다"
  3. 동작과 호흡 — 올릴 때 내쉬고 내릴 때 마시고, 몇 초씩
  4. 흔한 실수 하나 — 자료에 있는 주의사항에서 가장 중요한 하나만
  5. 마무리 — 숨 고르기, 오늘 한 것 한마디
- **숫자를 셉니다.** "하나, 둘, 셋" 처럼 실제로 셀 곳을 넣어 주세요.
- 문장은 짧게. 한 문장에 하나만 시킵니다.
- 이모지·괄호·따옴표를 쓰지 않습니다. 소리 내어 읽는 글입니다.
- 꼭 붙잡아야 할 대목 **한 곳만** `==이렇게==` 등호로 감쌉니다(화면에 형광펜으로 칠해집니다).

## 동작 이름 쓰는 법
표지 한가운데와 목록의 제목 왼쪽에 함께 붙는 **동작 그 자체의 이름표**입니다.
제목과 다릅니다. 제목은 손님을 부르는 문장이고, 동작 이름은 **뭘 하는 동작인지 한눈에 알리는 이름**입니다.

- **8자 내외.** 길면 표지에서 줄이 넘어갑니다.
- **`부위 + 도구·방식 + 동사`** 로 짭니다 — '어깨 벽 밀기', '종아리 폼롤러 밀기', '목 옆으로 늘이기'
- **Z·M 공통 한 벌만** 씁니다. 말투를 나누지 않습니다.
- 문장이 아니라 **이름**입니다. '~해 보세요', '~하면 좋아요' 같은 말끝을 붙이지 않습니다.
- 효과를 넣지 않습니다 — '어깨 통증 없애기' (X) / '어깨 벽 밀기' (O)
- 이모지·느낌표·물음표를 쓰지 않습니다.

## 안전 — 반드시 지킬 것
- 진단·치료를 단정하지 않습니다. "낫습니다" 금지.
- **아프면 멈추라는 말을 대본 안에 반드시 한 번 넣습니다.**
- 자료에 '한계까지', '반복불능까지' 같은 표현이 있어도 **그대로 옮기지 않습니다.**
  "힘들면 그만해도 됩니다" 쪽으로 눅여서 씁니다. 혼자 따라 하는 사람이 다치면 안 됩니다.
- 통증·저림이 있으면 범위를 줄이라는 안내를 넣습니다.
- **제가 드린 자료에 없는 내용**(추가 수치·효과·연구)을 덧붙였다면,
  그 문장 끝에 `〔확인 필요〕`를 붙여 주세요. 빼지 말고 표시만 해 주세요.

## 결과를 이 형식 그대로 주세요

### A. 카드 내용 — 그대로 붙여넣을 부분
```
[제목 · Z]
(18자 내외, 담백하게)

[제목 · M]
(18자 내외, 다정하게)

동작 이름: (8자 내외. 위 '동작 이름 쓰는 법'을 지켜 주세요)
종류: 스트레칭 / 운동 / 마사지 중 하나
소요 시간: (예 90초 · 1분 30초)
도구: (없으면 '없음')

[대본 · Z]
(위 다섯 마디대로. 문단 사이는 빈 줄로)

[대본 · M]

[검색 분류]
핵심 부위: (아래 목록에서 최대 3개)
연관 부위: (아래 목록에서 최대 6개)
부위 그룹: (아래 목록에서 고르기)
도구 성향: 전체 / 이완 도구 및 성향 위주 / 활력 도구 및 성향 위주 중 하나
```

### B. 동작 촬영 지시서 — 제가 보고 찍을 종이
```
[반복 동작]
한 바퀴 길이: (4~8초 중에서)
찍는 각도: 정면 / 측면 중 하나와 그 이유
시작 자세: (발 너비, 팔 위치, 시선까지 한 문장으로)
움직이는 곳: (어느 관절이 어느 방향으로 몇 도쯤)
속도: (올릴 때 몇 초, 버틸 때 몇 초, 내릴 때 몇 초)
끝나는 자세: (시작 자세와 같아야 반복이 매끄럽습니다)

[찍을 때 주의]
- (자세가 무너지기 쉬운 지점 하나)
- (화면에서 잘리면 안 되는 몸 부위)
```

## 고를 수 있는 값
- 부위: 머리 · 목 · 어깨 · 팔꿈치 · 손목 · 등 · 복부 · 허리 · 골반 · 무릎 · 발목 · 팔 · 다리
- 부위 그룹: 전체 · 목-머리 · 허리-골반 · 등-어깨 · 다리-발 · 팔-손
- 도구 성향: 전체 · 이완 도구 및 성향 위주 · 활력 도구 및 성향 위주

---

## 받은 결과로 하는 일

| 받은 것 | 무엇을 하나 |
|---|---|
| A. 카드 내용 | 관리자 → 바로카드 → **📋 대본 붙여넣기**에 통째로 |
| B. 반복 동작 | 이대로 4~8초 영상 촬영 → [🎬 동작 뽑기 도구](https://bmti-official.co.kr/tools/motion.html) → JSON을 '반복 동작' 칸에 |

- **동작 이름**은 붙여넣기로 '동작 이름' 칸에 저절로 들어갑니다. 표지 한가운데와 목록의 제목 왼쪽에 함께 나옵니다.
- 바로카드 표지는 **따로 사진을 준비하지 않습니다.** 올린 동작 영상의 0~5초가 소리 없이 돌아가며 표지 노릇을 합니다.
- `〔확인 필요〕` 표시가 남아 있으면 '공개'로 저장되지 않습니다. 사실을 확인하고 지운 뒤 공개하세요.
- 대본에 넣은 `==형광펜==`은 화면에만 칠해집니다. 음성으로 읽힐 때는 등호를 빼고 넣으세요.
