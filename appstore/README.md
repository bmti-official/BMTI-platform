# 앱스토어 미리보기 이미지

`*.png` — iPhone 6.9" 규격 **1320 × 2868**, 8장. 그대로 App Store Connect에 업로드할 수 있습니다.
(6.5"·iPad가 추가로 필요하면 `tools/build-appstore.py`의 `W, H`만 바꿔 다시 실행하세요.)

| 파일 | 내용 | 헤드라인 |
|---|---|---|
| 1-result-top | 결과지 상단(원본 캐릭터·유형) | 16가지 BMTI 유형 / 나는 어떤 유형일까? |
| 2-tendency | 4가지 성향 게이지 | 4가지 축으로 보는 움직임 성향 |
| 3-diary-mood | 다이어리 기분 선택 | 10초로 남기는 오늘의 기록 |
| 4-diary-body | 불편한 부위·강도·시점 | 몸까지 기록하는 건강 다이어리 |
| 5-awards | 기분 달력 · 말랑이 어워즈 | 기분 달력과 말랑이 어워즈 |
| 6-trend | 기분·불편함 추이 + {닉네임}의 밤 | 그래프로 보는 나의 한 달 |
| 7-relation | BMTI 관계도 · 공유 박스 | 16유형 관계도 / 친구랑 같이 보는 재미 |
| 8-share | 친구에게 공유하기 | 내 결과를 친구에게 자랑하기 |

## 다시 만들기

```bash
npm run dev                                   # 1) 로컬 서버
node tools/capture-appstore.cjs               # 2) 실제 화면 캡처 → appstore/raw/
.venv/bin/python3 tools/build-appstore.py     # 3) 문구·배경 합성 → appstore/
```

- **문구만 바꾸려면** `tools/build-appstore.py` 상단의 `SLIDES` 를 수정하세요.
  각 줄은 `(파일명, 배경색, 아이브로우, [[(문구, 색), ...], ...])` 형식입니다.
- 배경/강조색은 브랜드 팔레트를 씁니다 — 연옐로우 `#FDF6DC` · 연보라 `#EDE8F9` · 연핑크 `#FBE9F0`,
  강조 골드 `#C9975A` · 보라 `#8B7BD8` · 로즈 `#D6486D`.
- 캡처는 데모 데이터(24일치 기록, OLQM 유형)를 넣어 화면이 비어 보이지 않게 합니다.

> 참고: 이 폴더는 `public/`이 아니라 저장소 루트에 있어 **웹사이트로 배포되지 않습니다.**
